Islamic Time Infrastructure for the Open Web

Waqt is an open technical standard and API for computing, representing and interoperating with Islamic time — Maghrib-based day boundaries, astronomical events, Hijri dates and scheduling.

Foundational formalisation

Time is more than a timestamp.

A single coordinate frame replacing fragmented calculators, static timetables and midnight-based assumptions.

01 // Interval modelcontinuous

One temporal model

A Waqt day begins at local sunset (Maghrib) and ends at the next one. The reading is ordinary SI time elapsed since Maghrib, so an hour is always 60 minutes.

[Maghrib(L, D), Maghrib(L, D+1))

02 // Conventionsparameters

Configurable, never hidden

Astronomy and the day boundary are fixed. Conventions are explicit request parameters, and changing one moves only the event it governs.

fajr_angle18.0° default
isha_angle17.0° default
asr_ratio1.0 · 2.0 (Hanafi)
calendar_providerumm-al-qura (default)

Providers are listed by GET /v1/calendar.

03 // Clientsone contract

One envelope, many clients

Every response is the same documented envelope. The web viewer, CLI and the Python and JavaScript client libraries read it; none recompute it.
