Open temporal infrastructure

The Islamic day starts at Maghrib. Software should too.

Waqt is a Makkah-anchored, Maghrib-to-Maghrib civil time and Hijri calendar API: a precise, computable, interoperable way to represent the Islamic day — for mosques, watches, phones, institutions and any application you want to build.

Everything on this page comes from the public Waqt API. When the API cannot be reached, the clock switches to a clearly labelled, frozen demonstration sample — never to invented “live” numbers.

The problem

Software assumes midnight. The Islamic day does not.

Most calendars and schedulers treat the day as a 24-hour block starting at 00:00. A Waqt day runs from one Maghrib (sunset) to the next, and its length is whatever the sky says it is.

The boundary is Maghrib

The weekday changes at Maghrib, not at Gregorian midnight — Friday’s Jumu’ah day begins on Thursday evening. A midnight-based system gets the weekday wrong for the first part of the night.

The day is not exactly 24 hours

The interval between two Maghribs drifts with season and latitude. A fixed 24-hour assumption quietly misplaces events near the boundary.

Everyone re-implements it

Prayer-time logic, Hijri dates and day boundaries are rebuilt, slightly differently, in every app. There is no shared, testable, language-independent contract to build against.

How it works

One API computes the day. Your application only displays it.

  1. Place + instantYou send a location (and optionally an instant). Timezone and local date are resolved for you.
  2. Maghrib opens the dayThe Waqt day is [Maghrib(D), Maghrib(D+1)). The API returns both boundaries as exact instants.
  3. A real hour, counted from MaghribThe reading is ordinary SI time since Maghrib — 60-minute hours — resetting at the next Maghrib.
  4. Events are positionsFajr, sunrise, Dhuhr, Asr and Isha are instants placed on that day’s grid. Changing a method only moves its own event.
  5. Hijri date from one referenceThe Hijri date is computed once, globally, with Makkah as the reference — it never changes your local clock.

Today’s Waqt day, measured

Duration is taken from the opening and closing Maghrib instants returned by the API — nothing is hard-coded.
