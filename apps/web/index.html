The core insight

Time is more than a timestamp.

A single coordinate frame replacing fragmented calculators, static timetables, and midnight-based assumptions — giving every application a shared, verifiable foundation for Islamic time.

01 // Interval model

One temporal model

A Waqt day begins at local sunset (Maghrib) and ends at the next one. The reading is ordinary SI time elapsed since Maghrib, so an hour is always 60 minutes.

[Maghrib(L, D), Maghrib(L, D+1))

02 // Conventions

Configurable, never hidden

Astronomy and the day boundary are fixed. Conventions are explicit request parameters — changing one moves only the event it governs.

fajr_angle18.0°
isha_angle17.0°
asr_ratio1.0 · 2.0 (Hanafi)
calendar_providerumm-al-qura

Conceptual architecture

Four distinct concerns, kept separate

Software often conflates day boundaries, clock readings, prayer events, and Hijri calendar labels. Waqt models them as four independent layers so applications can use each one correctly.

Optional feature · AT/BT Display

After Twelve / Before Twelve

An optional human-friendly display layer — analogous to AM/PM but mapped to the Waqt clock: hours 00–11 are BT (Before Twelve), hours 12–23 are AT (After Twelve).

AT/BT is presentation only. It does not change canonical Waqt time, prayer events, day boundaries, calculations, or the Hijri date.
