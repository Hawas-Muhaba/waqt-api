Quickstart

Getting started

From a clone of the repository to a first response.

  1. 01 Install the packages from the repository root.
  2. 02 Start the API with uvicorn waqt.api:app --port 8000.
  3. 03 Ask for the current Waqt day for any place.
pip install -e ./core -e . -e ./local
uvicorn waqt.api:app --port 8000

curl "http://localhost:8000/v1/waqt?lat=9.0192&lon=38.7525"
