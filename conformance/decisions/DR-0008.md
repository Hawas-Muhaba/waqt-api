## Context
A clean-room implementation written from SCHEDULING.md alone passed 108 of 116 vectors; the 8 failures were rules stated nowhere in prose.

## Decision
The five rules are written in SCHEDULING.md section 11 and each is a requirement bound to existing vectors (inclusive flag, default event slot, empty windows, undefined slots and the skip policy, stepping through an undefined day).

## Evidence
The rules were taken from what the existing normative vectors and both implementations already do; no vector expectation changed.

## Consequences
Prose and requirement tags only. Behaviour is unchanged.

## Alternatives considered
Leave them implicit: rejected, that is exactly the gap Sprint 15 measured.

## Configurability (religious / regional conventions)
Not configurable: protocol semantics, not conventions.

## Dissent and unresolved points
None.

## Reopen when
A vector and the prose disagree in future: the prose governs and the vector is an erratum (GOVERNANCE.md section 4).

## Vectors affected
legacy-scheduling: existing vectors tagged SCH-009..013.
